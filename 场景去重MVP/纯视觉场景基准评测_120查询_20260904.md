# 纯视觉场景基准评测（120 查询）

评测日期：2026-09-04

## 目标与约束

- 只评估场景视觉模块，模型输入仅包含每个 Task 均匀抽取的 8 帧 RGB 图像。
- `scene`、`task_name`、`details` 只用于页面解释，严禁参与召回、排序和打分。
- 固定复用已完成的 120 个查询、600 个 `query-reference` Pair 人工场景标签。
- 前 80 个查询为开发集，用于比较算法和选择权重；后 40 个为锁定集，只在方案确定后验收一次。
- 每个查询当前只有 5 个已标候选，因此本轮衡量的是“候选内部排序质量”，还不是对 100/1000 个全库资产的完整召回率。

## 指标定义

- NDCG@5：同时衡量 5 个候选的整体排序是否接近人工等级排序，越接近 1 越好。
- Top1 人工最优率：模型第一名是否属于该查询人工最高等级候选。
- Top1 等级≥2率：模型第一名是否达到“布局明显相似”或“同一物理工位”。该指标受测试集正样本比例影响，只作辅助观察。
- Hit@3（有正样本查询）：当 5 个候选中存在等级≥2时，前三名是否至少命中一个。

## 第一轮对比

| 方案 | 80条开发集 NDCG@5 | 开发集 Top1人工最优率 | 40条锁定集 NDCG@5 | 锁定集 Top1人工最优率 |
|---|---:|---:|---:|---:|
| 整体 Task 余弦 100% | 0.8442 | 63.75% | 0.8670 | 70.00% |
| 原始余弦 65% + 帧覆盖 35% | 0.8524 | 66.25% | 0.8738 | 72.50% |
| 开发集最佳：原始余弦 60% + 帧覆盖 40% | **0.8547** | **67.50%** | **0.8738** | **72.50%** |
| 旧线上归一化整体分 70% + 帧覆盖 30% | 0.8407 | 63.75% | 0.8789 | 72.50% |

开发集上的 0%～100% 权重扫描选择了“整体 Task 原始余弦 60% + 双向逐帧覆盖 40%”。该配方在锁定集上相较纯整体余弦：

- NDCG@5：0.8670 → 0.8738；
- Top1 人工最优率：70.00% → 72.50%；
- Hit@3（存在等级≥2的查询）：保持 100%。

## 已应用的迭代

正式 `/search/url` 与 `/search/upload` 检索入口已固定为纯视觉模式：

1. 从 Task 帧范围均匀抽取 8 帧；
2. CLIP ViT-B/32 编码 8 个帧向量；
3. 8 个向量平均并归一化，得到整体 Task 向量；
4. Faiss 按整体向量余弦召回 30 个候选；
5. 对召回候选计算双向逐帧最佳匹配覆盖；
6. 按 `0.60 × 整体余弦 + 0.40 × 帧覆盖` 重排并返回 Top-K。

API 即使收到历史 `description` 字段也会忽略，响应中的 `query_mode` 为 `pure_visual_scene_v1`。

## 结论与下一轮

第一轮证明：保留每帧特征并做双向覆盖，可以稳定改善 Top-K 排序；但提升幅度仍有限。下一轮不应继续在同一 80 条上反复调小数权重，而应优先分析错误类型，再比较具备时序建模的视频编码器或更合理的关键帧采样。后 40 条继续保持锁定，只有方案在开发集定稿后才验收。
